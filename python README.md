## Overview
This repository contains Python Activity-Based Learning case studies numbered 41 to 50. The programs demonstrate Python concepts such as lists, nested lists, tuples, loops, conditional statements, calculations, validation, and data analysis.

- **Case 49:** Tuple-Based Product Catalogue Audit
- **Case 50:** Tuple-Based Route Distance Analysis

## How to Run
1. Install Python 3.
2. Open a terminal or command prompt in the folder containing the Python files.
3. Run a program with:
   ```bash
   python filename.py
   ```
   Replace `filename.py` with the name of the Python source file you want to run.

## Requirements
- Python 3
- No external libraries are required for most programs. Case 50 uses Python's built-in `math` module.

## Learning Outcomes
- Use lists, nested lists, and tuples to represent data.
- Apply loops and conditional statements.
- Calculate totals, distances, and rankings.
- Validate records and identify exceptions.
- Test programs with different input cases.
